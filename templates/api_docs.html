Use PhishGuard from code.

The hosted console exposes the same URL model over a small JSON API, so a static front-end, a mail gateway, or a CI check can score links without a browser.

NO AUTH FOR SCANS
01 / SCORE A URL

POST /api/v1/scan/url

POST

Send {"url": "https://example.com"} as JSON. The URL is parsed and scored; it is never fetched, so nothing on that host can respond to the request.

cURL 
curl -X POST {{ request.url_root }}api/v1/scan/url \
  -H "Content-Type: application/json" \
  -d '{"url": "http://secure-account-verify.example/login"}'
Response · 201
{
  "scan_id": 42,
  "scanned_at": "2026-01-01 12:00:00",
  "url": "http://secure-account-verify.example/login",
  "result": "PHISHING",
  "risk_level": "High",
  "probability": 91.4,
  "features": { "url_length": 46, "has_login_word": 1, "...": "..." },
  "engine": "phishguard-url-random-forest",
  "disclaimer": "Structural model output only."
}

Status 400 means the URL failed validation, and 429 means the caller went over the shared rate limit.

02 / HEALTH

GET

Small probe for Render, uptime monitors, and load balancers. Returns 200 when the database responds and the model is loaded, otherwise 503.
