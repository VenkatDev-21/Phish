Two flat subdirectories with a clear template → static dependency direction:
- `templates/` is a Jinja2 view layer. `base.html` defines the app shell (sidebar navigation, topbar, footer) and exposes `{% block title %}`, `{% block page_name %}`, `{% block content %}`, and `{% block page_scripts %}`; every other template extends it via `{% extends "base.html" %}` and fills those blocks. Per-page scripts are registered through the `page_scripts` block using Flask's `url_for('static', filename=...)`, so each page can opt into an extra JS module (e.g. `dashboard.js`).
- `static/` holds plain CSS (`style.css`) and vanilla ES modules loaded with `defer`: `app.js` is global (URL preview, file/email upload, CSRF, sidebar toggle, 401 unlock redirect), while `dashboard.js`, `authentication_analysis.js`, and `history.js` are page-scoped.
- The UI is a single-page-style SPA shell: the sidebar routes to Flask endpoints (`home`, `email_scanner`, `file_scanner`, `authentication_analysis`, `history`, `api_docs`, `dashboard`) and pages communicate with the backend via `fetch`/XMLHttpRequest returning JSON; async scans use a status-polling pattern (`data-statusUrl` polled every 3s until `complete`/`failed`).
- No build step or framework — served directly by the Flask app's static route.
