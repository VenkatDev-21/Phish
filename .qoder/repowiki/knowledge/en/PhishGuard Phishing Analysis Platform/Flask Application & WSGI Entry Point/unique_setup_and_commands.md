Local development runs via `python app.py` (uses `127.0.0.1:5000`, 5 GiB uploads, ephemeral secret). Production deployments set `FLASK_SECRET_KEY` (≥16 chars), optionally `PHISHGUARD_DATA_DIR`, `MAX_UPLOAD_BYTES`, `PORT`, `PHISHGUARD_ACCESS_CODE`, `PHISHGUARD_ALLOWED_ORIGINS`, `PHISHGUARD_RATE_LIMIT`, `PHISHGUARD_EXTERNAL_SUBMISSIONS`; `RENDER` or `VERCEL` env vars switch the environment to production. The WSGI target for gunicorn is `wsgi:app`.
